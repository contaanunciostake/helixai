00_PARAR_SISTEMA.bat
   └─ Para TODOS os processos do HelixAI
   └─ Use ANTES de reiniciar ou ao finalizar o trabalho

01_LIMPAR_SISTEMA.bat
   └─ Limpa cache, sessões WhatsApp, logs
   └─ Use quando houver problemas de cache

02_VERIFICAR_SISTEMA.bat
   └─ Faz diagnóstico completo
   └─ Verifica Node.js, Python, MySQL, portas, etc
   └─ Use ANTES de iniciar para garantir que está tudo OK

03_INICIAR_SISTEMA_COMPLETO.bat ⭐ PRINCIPAL
   └─ Inicia TODOS os componentes do HelixAI
   └─ Backend, Bot, WhatsApp, CRMs, Landing, Afiliados, etc
   └─ Use para iniciar TODO o sistema

⚡ FLUXO RÁPIDO DE USO DIÁRIO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

OPÇÃO 1 - Atalho Rápido:
   Duplo clique em: 🚀_INICIAR_TUDO.bat (na raiz)

OPÇÃO 2 - Completo com Verificação:
   1. Execute: 02_VERIFICAR_SISTEMA.bat
   2. Execute: 03_INICIAR_SISTEMA_COMPLETO.bat

Ao Finalizar:
   1. Execute: 00_PARAR_SISTEMA.bat
   OU
   Duplo clique em: 🛑_PARAR_TUDO.bat (na raiz)

❓ PROBLEMAS COMUNS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

"Porta já está em uso"
   → Execute: 00_PARAR_SISTEMA.bat

"Erro ao conectar WhatsApp"
   → Execute: 01_LIMPAR_SISTEMA.bat (escolha limpar sessões)
   → Escaneie QR Code novamente

"MySQL não está rodando"
   → Abra XAMPP Control Panel
   → Inicie MySQL

"Erro ao instalar dependências"
   → Execute: npm cache clean --force
   → Delete node_modules e rode npm install novamente


💡 DICAS IMPORTANTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

• Configure arquivos .env antes da primeira execução
